# PR Review: systemeio/backend#22333

## Verdict

Changes requested.

## Key finding

1. **High** - BC break in `LabelInterface` / label hierarchy:
   - `src/Entity/WhiteLabel/LabelInterface.php` removes `getStatus()` and `isActive()`.
   - `src/Entity/WhiteLabel/AbstractLabel.php` and `src/Entity/WhiteLabel/WhiteLabel.php` no longer provide these methods.
   - Existing codebase still relies on these methods for active-label checks and behavior branching.

## Why this blocks merge

This is a compatibility-breaking change to a core domain contract (`LabelInterface`) without an atomic migration of all consumers. The risk is runtime breakage and logic regression in active/inactive white-label handling.

## Recommendation

- Keep compatibility by restoring `getStatus()` and `isActive()` contract and implementation, or
- Include complete migration of all call sites in the same PR with tests proving no regressions.
